Project Implementation Instructions
Scenario: Web Site for Gloucestershire Constabulary to reduce bicycle theft
The purpose of the project is to implement a website that will help Gloucestershire Constabulary to reduce bicycle theft. The website will also help Gloucestershire Constabulary to reduce number of Police Officers currently involved in investigating these crimes. Using the proposed system End-Users will register their bicycle to keep a record of frame number, bicycle image and other relevant manufacturers’ details of the bicycle.  End-User will also report a stolen bicycle using the system.

User Classes and Characteristics
There are mainly two types of user: 

Public
Police
Public can do the following using the website:

Public must register personal and login details
Public can login to the system
Public can register one or more bikes. Table 1 below shows a list of bicycle attributes that can be used for registering bikes.
Public can report a previously registered bicycle stolen
Public can check progress / status of investigation of a reported bike
Police can do the following using the website:

An Admin Police can enrol other police officers, and create login details (user name and password) for them
Police officers can login to the system
Police officers can view a list of stolen bicycles reported in a specific week/ month/ year
Police officers can update investigation status of reported bicycles
