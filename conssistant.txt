CONSISTENT DATABASE FEATURES & PATTERNS
=========================================

1. Primary Key Standard:
   - Every table uses 'id' as the Primary Key.
   - All Primary Keys are INT type and use AUTO_INCREMENT.

2. Audit & Timestamping:
   - Most tables (users, bicycles, report, activity_log) include a 'created_at' column.
   - 'created_at' consistently defaults to CURRENT_TIMESTAMP for automated tracking.

3. Foreign Key Conventions:
   - Relationships follow a clear 'table_id' naming pattern (e.g., 'user_id' in bicycles, 'bicycle_id' in report).

4. Security Patterns (DAOs):
   - Strict use of PDO Prepared Statements (?) across all database interactions to prevent SQL injection.
   - Sensitive data handling: UserDAO explicitly unsets 'password' fields before returning user objects.
   - Password Hashing: BCRYPT is consistently used for storing user credentials.

5. Data Types & Enums:
   - ENUM types are used for status management to enforce data integrity (e.g., 'role' in users, 'status' in bicycles, 'investigation_status' in report).
   - Standardized VARCHAR lengths for common fields (e.g., email: 100, names: 50).

6. Data Access Layer (DAO Pattern):
   - All database logic is modularized into 'includes/' files following the DAO pattern.
   - Consistent function naming (e.g., getBikeDetail, getUserDetail) across different modules.

7. Centralized Configuration:
   - All database operations depend on a shared $pdo instance initialized in 'database/config.php'.
