SECURITY AUDIT & FIXES - APRIL 2026
==================================================
1. Insecure File Uploads (api/bicycles.php):
   - Problem: No validation on file type or size; potential for malicious script uploads.
   - Fix: Added MIME type checking (JPG/PNG/WebP only) and a 5MB size limit.
   - Fix: Files are now renamed to a random UUID to prevent overwriting and path traversal.

2. SQL Injection Risk (includes/ReportDAO.php):
   - Problem: Dynamic query building in updateReportEntry could allow column injection.
   - Fix: Implemented strict "Allowed Fields" whitelist.
   - Fix: Ensured all dynamic values use PDO prepared statement placeholders.

3. Role Enforcement (api/reports.php):
   - Problem: Police were able to hit the 'create' endpoint via raw POST.
   - Fix: Added explicit check to prevent police accounts from creating theft reports.

4. Data Integrity:
   - Verified that all database interactions use PDO which prevents standard SQL injection.
   - Ensured session_start() is consistent across all API entry points.
